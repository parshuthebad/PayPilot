# PayPilot AI

AI-powered payment command center for the PayPal AI Hackathon.

This repository contains the complete PayPilot AI prototype, including:
- AI Command Center
- Approval-gated PayPal payment workflow
- PayPal Sandbox Orders API integration
- PayPal webhook endpoint
- Transaction/customer analytics
- AI risk watchlist
- Weekly AI report
- Responsive frontend demo
- FastAPI backend

## Run  the  demo

Extract `paypilot-ai.zip`, then open:

`paypilot-ai/frontend/index.html`

## Run the backend

See `paypilot-ai/README.md` for PayPal Sandbox setup and FastAPI instructions.

## Security

Never commit PayPal credentials or AI provider keys. Use Sandbox credentials and keep financial actions approval-gated.
